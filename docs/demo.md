# Roteiro de demonstração

1. Abrir SPA e mostrar projetos e usuários.
2. Criar uma história: Como analista, quero registrar um requisito, para organizar o desenvolvimento.
3. Criar cenário com DADO, QUANDO e ENTAO.
4. Mostrar validação do cenário inválido.
5. Registrar sugestão manualmente, mostrando ferramenta, prompt e conteúdo.
6. Demonstrar rejeição sem motivo bloqueada e rejeição válida.
7. Mostrar que uma sugestão decidida não pode ser alterada.
8. Exportar o `.feature` e abrir o arquivo.
9. Mostrar painel de resumo e testes automatizados.
